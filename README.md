# 🐍 Python Exercise Hub

¡Bienvenido! Este repositorio es una colección curada de ejercicios, retos y soluciones de programación en Python que he ido realizando a lo largo de un año desde el verano pasado. Aquí encontrarás desde lógica básica hasta implementaciones más avanzadas, diseñado tanto para practicar sintaxis como para resolver problemas algorítmicos.

Hasta el momento podrás encontrar ejercicios varios de lógica de creación y gestión con diferentes metodologias, proyectos con TKinter y con Flask.

Por último, está en desarrollo la realización de ejercicios de simulación para comprender como se educa una IA con metodología DeepLearning.

---

## 🚀 Cómo empezar

Si deseas probar estos ejercicios de forma local, sigue estos pasos:

1.  **Clona el repositorio:**
    ```bash
    git clone [https://github.com/Henner13/Python25-26.git](https://github.com/Henner13/Python25-26.git)
    ```
2.  **Entra a la carpeta:**
    ```bash
    cd nombre-del-repo
    ```
3.  **Ejecuta cualquier ejercicio:**
    ```bash
    python3 ruta/del/ejercicio.py
    ```

---
